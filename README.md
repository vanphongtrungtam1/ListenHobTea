# VSTEP Listening — Teacher

Đây là phiên bản dành cho giáo viên, có chức năng **Key** và **Evidence**.

## Đưa lên GitHub Pages

1. Tải toàn bộ file trong gói lên cùng một repository và giữ tất cả file ở thư mục gốc.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, chọn nhánh chứa các file và thư mục **/ (root)**.

Trang chính sử dụng `index.html`. Không đổi tên các file audio, hình ảnh, CSS hoặc JavaScript.
